9. Simulating Ideal Bose Gas and Bose-Einstein Condensate

Back to Contents
In this tutorial, I will explain the exact steps of building a working simulation of ideal Bose gas in a 3-dimensional periodic box of length \(L\). As the temperature is lowered, one can see the Bose-Einstein Condensate forming, as a large fraction of bosons occupy the ground state. Click here to jump to the simulation.

Bosons and Indistinguishable Particles Density Matrix

All elementary particles are either fermions (half integer spin) or bosons (integer spin). Fermions obey the Pauli exclusion principle, while bosons may occupy the same quantum state. In this simulation we consider ideal Bose gas, meaning that the particles do not interact with (attract or repel) each other.

The first step of building the simulation is to derive an expression for the density matrix elements of an \(N\)-indistinguishable-particle system. To achieve that we start with the case of \(N\) distinguishable particles. Let \(\{x\} \equiv \{x_1, ...,x_N\}\) denote the particle positions, i.e. particle \(1\) at \(x_1\), ..., particle \(N\) at \(x_N\), and let \(\{\sigma\} \equiv \{\sigma_1, ..., \sigma_N\}\) represent the system's quantum state where particle \(1\) is in state \(\sigma_1\), ..., particle \(N\) in state \(\sigma_N\). The elements of the density matrix for \(N\)-distinguishable-particle system are given by \[ \rho^{\text{dis}}(\{x\},\{x' \}, \beta) = \sum_{\{\sigma\}}\psi_{\{\sigma\}}(x_1,...,x_N)e^{-\beta E_{\{\sigma\}}}\psi_{\{\sigma\}}^*(x_1', ...,x_N') \] where \(\psi_{\{\sigma\}}\)'s are orthonormal wave functions (eigenfunctions) of \(N\)-particle system for (total) energy eigenstate \(E_{\{\sigma\}}\), and \(\beta\) is the inverse temperature, defined as \(\beta = \frac{1}{k_B T}\), where \(T\) is the temperature of the system and \(k_B\) the Boltzmann constant. This is the quantum coherence between state 1: particle \(1\) at \(x_1\), ..., particle \(N\) at \(x_N\), and state 2: particle \(1\) at \(x_1'\), ..., particle \(N\) at \(x_N'\), at temperature \(T\).

For ideal particles, the wave function \(\psi_{\{\sigma\}} = \psi_{\{\sigma_1, ..., \sigma_N\}}\) can be written as the product of the single-particle wave functions of each particle, and the total energy \(E_{\{\sigma\}}\) of the \(N\) particles is the sum of the single-particle energy levels: \[ \begin{gather} \psi_{\{\sigma\}}(x_1,...,x_N) = \prod_{k=1}^N \psi_{\sigma_k}(x_k)\\ E_{\{\sigma\}} = \sum_{k=1}^N E_{\sigma_k} \end{gather} \] Recall that the single particle density matrix elements are \[ \rho(x_k, x_k', \beta) = \sum_{\sigma_k}\psi_{\sigma_k}(x_k) e^{-\beta E_{\sigma_k}}\psi_{\sigma_k}^*(x_k') \] Substituting these in \(\rho^{\text{dis}}(\{x\},\{x' \}, \beta)\), we see that the elements of the \(N\)-ideal-particle system density matrix can be written as the product of single-particle density matrices: \[ \rho^{\text{dis}}(\{x\},\{x' \}, \beta) = \prod_{k=1}^N\rho(x_k,x_k',\beta) \] Since bosons are indistinguishable from one another, the wave function of the system of \(N\) ideal bosons must be permutation invariant. If \(\{x_P\} \equiv \{x_{P_1},...,x_{P_N}\}\) is a permutation of \(\{x\} \equiv \{x_1,...,x_N\}\), then we must have \[ \psi_{\{\sigma\}}^{\text{bosons}}(x_{P_1},...,x_{P_N}) = \psi_{\{\sigma\}}^{\text{bosons}}(x_1,...,x_N) \] For each eigenstate \(\{\sigma\}\), we derive the wave function \( \psi_{\{\sigma\}}^{\text{bosons}}(x_1,...,x_N)\) for \(N\) bosons, starting with the sum of the \(N\)-distinguishable-particle wavefunctions across all permutations of the spatial coordinates of the particles: \[ \Phi_{\{\sigma\}}(x_1,...,x_N) \equiv \sum_{P}\psi_{\{\sigma\}}^{\text{dis}}(x_{P_1},...,x_{P_N}) = \sum_{P}\prod_{k}\psi_{\sigma_k}(x_{P_k}) \] Note that \(\Phi\) is permutation invariant. To make the eigenfunctions orthonormal, \(\Phi\) needs to be scaled by a constant factor. Let \(C\) be the factor. We have (notation: \(\int dx\) integrating over the entire measure space of the variable \(x = (x_1, ..., x_N)\)) \[ \begin{aligned} 1 & = \int (C\Phi_{\{\sigma\}}(x_1,...,x_N))(C\Phi_{\{\sigma\}}(x_1,...,x_N))^* dx\\ & = |C|^2\int \bigg(\sum_{P}\prod_{k}\psi_{\sigma_k}(x_{P_k})\bigg)\bigg(\sum_{Q}\prod_{k}\psi_{\sigma_k}(x_{Q_k})\bigg)^*dx\\ & = |C|^2\int \sum_{P}\sum_{Q}\bigg(\prod_{k}\psi_{\sigma_k}(x_{P_k})\psi_{\sigma_k}^*(x_{Q_k})\bigg)dx \end{aligned} \] where \(P\), \(Q\) are independent permutations. To find \(C\) that normalizes \(\Phi\), we need to evaluate the double sum of integrals. Recall that the single particle wave functions are orthonormal: \(\int \psi_{\sigma_k}\psi_{\sigma_j}^* dx = 1\) if \(\sigma_k = \sigma_j\) and equals \(0\) otherwise. Therefore, in the double sum, only the terms for which variables \(x_{P_k}\) and \(x_{Q_k}\) are mapped to the same state remain. In addition, because bosons are allowed to occupy the same quantum state, some of the integrals that evaluate to \(1\) are repeated because the integrands are the same. For example, for \(N = 3\), if all three particles are in the ground state, \(\{\sigma\} \equiv \{\sigma_1, \sigma_2, \sigma_3\} =\{0,0,0\}\), then \(|\psi_{\sigma_1}(x_1)|^2|\psi_{\sigma_2}(x_2)|^2|\psi_{\sigma_3}(x_3)|^2\) and \(|\psi_{\sigma_1}(x_2)|^2|\psi_{\sigma_2}(x_3)|^2|\psi_{\sigma_3}(x_1)|^2\) are identical. Let \(n_s\) be the occupation number of each unique state \(s\). For each pair of \(x_{P_k}\) and \(x_{Q_k}\) that are mapped to the same \(s\), there are \((n_s!)\) integrals that evaluate to \(1\). The total number of repeated states is \(\prod_s (n_s!)\). Therefore, for \(N\) bosons, counting the spatial permutations (\(N!\) integrals where \(x_{P_k}\) and \(x_{Q_k}\) are mapped to the same \(\sigma_k\)) and the repeated quantum states, we have \[ \begin{gather} 1 = |C|^2 (N!)\prod_s (n_s!) \end{gather} \] Hence, \(C = \sqrt{\frac{1}{N!\prod_s (n_s!)}}\), and we have \[ \begin{aligned} \psi_{\{\sigma\}}^{\text{bosons}}(x_1,...,x_N) & = \sqrt{\frac{1}{N!\prod_s (n_s!)}}\sum_{P}\psi_{\{\sigma\}}^{\text{dis}}(x_{P_1},...,x_{P_N})\\ & = \sqrt{\frac{1}{N!\prod_s (n_s!)}} \sum_{P}\prod_{k}\psi_{\sigma_k}(x_{P_k}) \end{aligned} \]
Let \(\{n\} = \{n_1, n_2,...\}\) denote the unique states occupied by the \(N\) bosons in states \(\{\sigma\} \equiv \{\sigma_1, ..., \sigma_N\}\) defined by the set of occupation numbers \(n_s\) for each unique state. There are \(C^N_{n_1} C^{N-n_1}_{n_2} C^{N-n_1-n_2}_{n_3}... = \frac{N!}{\prod_s (n_s!)}\) ways the bosons can occupy the unique states. Hence \(\sum_{\{n\}} = \sum_{\{\sigma\}}\frac{\prod_s (n_s!)}{N!}\). The density matrix elements of the \(N\)-boson system are \[ \begin{aligned} \rho^{\text{bosons}}(\{x\},\{x' \}, \beta) & = \sum_{\{n\}}\psi_{\{n\}}^{\text{bosons}}(x_1,...,x_N)e^{-\beta E_{\{n\}}}\psi_{\{n\}}^{\text{bosons}*}(x_1', ...,x_N')\\ & = \frac{1}{N!\prod_s (n_s!)}\sum_{\{n\}}\bigg(\sum_{P}\prod_{k}\psi_{\sigma_k}(x_{P_k})\bigg)e^{-\beta E_{\{n\}}} \bigg(\sum_{Q}\prod_{k}\psi_{\sigma_k}(x'_{Q_k})\bigg)^*\\ & = \frac{1}{N!\prod_s (n_s!)} \frac{\prod_s (n_s!)}{N!} \sum_{\{\sigma\}}\sum_{P}\sum_{Q}\bigg( \prod_{k}\psi_{\sigma_k}(x_{P_k})e^{-\beta E_{\sigma_k}}\psi_{\sigma_k}^*(x'_{Q_k})\bigg)\\ & = \bigg(\frac{1}{N!}\bigg)^2 \sum_{P}\sum_{Q}\sum_{\{\sigma\}}\bigg( \prod_{k}\psi_{\sigma_k}(x_{P_k})e^{-\beta E_{\sigma_k}}\psi_{\sigma_k}^*(x'_{Q_k})\bigg) \end{aligned} \] Because rearranging the terms in the product does not change the value, we can redefine the permutation \(P= P\circ Q^{-1}\), thus absorbing one of the permutations and canceling out one of the \(1/N!\), since we are adding the same number \(N!\) times: \[ \begin{aligned} \rho^{\text{bosons}}(\{x\},\{x' \}, \beta) & = \frac{1}{N!} \sum_{P}\sum_{\{\sigma\}}\bigg( \prod_{k}\psi_{\sigma_k}(x_{k})e^{-\beta E_{\sigma_k}}\psi_{\sigma_k}^*(x'_{P_k})\bigg)\\ & = \frac{1}{N!} \sum_{P}\rho^{\text{dis}}(\{x\},\{x'_P\},\beta) \end{aligned} \] Hence the density matrix of \(N\) ideal bosons is the average of the density matrices of \(N\) distinguishable particles across all permutations of spatial coordinates of the particles.

Ideal Bosons Partition Function

Recall that the partition function \(Z\) (size of total statistical weights for all energy eigenstates) is the trace of the density matrix. For \(N\) bosons, the partition function is: \[ Z^{\text{bosons}}_N = \sum_{\{n\}}e^{-\beta E_{\{n\}}} = \int \rho^{\text{bosons}}(\{x\},\{x\},\beta) dx \] where \(\{n\} = \{n_1, n_2, ...\}\) is the unique system state defined by the occupation numbers \(n_s\) of each unique single particle quantum state \(s\), and \(\{x\}\equiv \{x_1,...,x_N\}\) is the spatial coordinates of the particles. Therefore, substituting in the density matrix for \(N\) bosons and \(N\) distinguishable particles, we can write the bosons partition function in terms of single particle density matrix elements: \[ \begin{aligned} Z^{\text{bosons}}_N & = \frac{1}{N!}\int \sum_{P}\rho^{\text{dis}}(\{x\},\{x_P\},\beta) dx\\ & = \frac{1}{N!} \sum_{P}\int \prod_{k=1}^N\rho(x_k,x_{P_k},\beta) dx\\ & = \frac{1}{N!} \sum_{P} Z^P_N \end{aligned} \] where \(P\) is a permutation of the indices of \(\{x\}\). For each permutation, we define \(Z^P_N = \int \prod_{k=1}^N\rho(x_k,x_{P_k},\beta) dx \). This is the statistical weight (unnormalized probability) of a permutation of particle positions \(\{x\} = \{x_1, ..., x_N\}\). Hence \(Z^{\text{bosons}}_N\) is the average of the statistical weights over all permutations of particle positions.

Note that \(Z\) may contain off-diagonal elements of the single particle density matrix. For example, for \(N=4\) and the permutation \(P = (1)(234)\) (that is, index \(1 \to 1\), \(2 \to 3\), \(3 \to 4\), \(4 \to 2\)), we have \[ Z^{(1)(234)}_4 = \int \int \int \int \underbrace{\rho(x_1,x_1,\beta)}_{\text{diagonal element}} \underbrace{\rho(x_2,x_3,\beta) \rho(x_3,x_4,\beta) \rho(x_4,x_2,\beta)}_{\text{off-diagonal elements}} dx_1dx_2dx_3dx_4 \] Recall that \(\rho\) has a convolution property. For integer \(k>1\), we have: \[ \rho(x_0,x_{k}, k\beta) = \underbrace{\int\int...\int}_{k-1 \text{ integrals}} \rho(x_0,x_1,\beta)\rho(x_1,x_2,\beta)...\rho(x_{k-1},x_{k},\beta)dx_1dx_2...dx_{k-1} \] Therefore, \(Z^{(1)(234)}_4\) becomes \[ \begin{aligned} Z^{(1)(234)}_4 & = \underbrace{\int \rho(x_1,x_1,\beta) dx_1}_{\text{weight of the cycle }(1)} \underbrace{\int \int \int \rho(x_2,x_3,\beta) \rho(x_3,x_4,\beta) \rho(x_4,x_2,\beta) dx_2dx_3dx_4}_{\text{weight of the cycle }(234)}\\ & = \int \rho(x_1,x_1,\beta) dx_1 \int \bigg( \int \int \rho(x_2,x_3,\beta) \rho(x_3,x_4,\beta) \rho(x_4,x_2,\beta) dx_3dx_4 \bigg) dx_2\\ & = \int \underbrace{\rho(x_1,x_1,\beta)}_{\text{diagonal element}} dx_1 \int \underbrace{\rho(x_2,x_2,3\beta)}_{\text{diagonal element}}\, dx_2 \end{aligned} \] We can remove the off-diagonal elements in a permutation cycle of length \(k\) by multiplying the inverse temperature \(\beta\) by \(k\). Now \(Z_4^{(1)(234)}\), which contains two permutation cycles, becomes the product of two single particle partition functions, with \(\beta\) scaled by the lengths of the permutation cycles. From now on we will use lower case \(z\) to denote the single particle partition function and use \(z_k\) for the statistical weight (unnormalized probability) of a cycle of length \(k\). (Note that any cycles of the same length \(k\) are equally weighted, since we can just relabel the variables \(x_i\) and get the identical integral.) Then, \[ Z^{(1)(234)}_4 = z_1(\beta)z_3(\beta) = z(\beta)z(3\beta) \] (N.B.) For a free particle (potential \(\hat{V} = 0\)), a Wiener process and a Brownian bridge naturally arise from the weight of a permutation cycle of length \(k\). Let \(x_m\), \(x_{m+1}\), ..., \(x_{m+k-1}\) be the particle coordinates in the cycle. We have \[ z_k(\beta) = z(k \beta) = \int \rho^{\text{free}}(x_m, x_m, k\beta) dx \] where \[ \begin{gather} \rho^{\text{free}}(x_m, x_m, k\beta) = \underbrace{\int...\int}_{k-1\text{ integrals}} \rho^{\text{free}}(x_m,x_{m+1},\Delta_{\tau})...\rho^{\text{free}}(x_{m+k-1},x_{m},\Delta_{\tau}) dx_{m+1}...dx_{m+k-1}\\ \text{where }\;\Delta_{\tau} = \frac{k\beta}{k} = \beta, \; \text{ and }\; \rho^{\text{free}}(x_j, x_{j+1}, \Delta_{\tau}) = \sqrt{\frac{m}{2\pi\hbar^2 \Delta_{\tau}}} e^{-\frac{m(x_j-x_{j+1})^2}{2\hbar^2\Delta_{\tau}}} \end{gather} \] If we treat \(\Delta_{\tau} = \beta\) as the time increment, then this describes the path of a Wiener process \[ dX_t = \sqrt{\frac{\hbar^2}{m}} dW_t \] This means that we can sample the spatial coordinates \(x_{m}\), ..., \(x_{m+k-1}\) from a path of the Wiener process that starts at \(x_{m}\) at time \(0\) and arrives at \(x_{m}\) again at time \(k \beta\), and the inbetween nodes with time increment \(\beta\) are the coordinates \(x_{m+1}\), ..., \(x_{m+k-1}\), each node anchored to the previous one. For the derivation of the Brownian bridge distribution, check out this page.

(The density matrix becomes slightly different when we enforce a periodic boundary condition on the free particle, but it still describes a Wiener process, which will be discussed later.)

Recursive Relationship of Partition Function

For the simulation, we need to sample from the (unnormalized) probabilities \(Z^P_N\) of permutations of \(\{x\}\) to get the particles' spatial coordinates. However, because for \(N\) particles there is a total of \(N!\) permutations, for large \(N\) it becomes difficult to write out the statistical weights for all of them. A better way is to use a recursive method that allows us to sample from only \(N\) probabilities.

For any permutation of \(N\) elements (e.g. \(\{x_1, ..., x_N\}\)), the cycle that contains element \(N\) is called the last element cycle (element \(N\) is not special, but is chosen for convenience; one can choose any other element). If the last element cycle has length \(k\), then there are \(N-k\) elements that are not in this cycle. We can compute the partition function \(Z_N\) by summing up the statistical weights of the last element cycles from length \(1\) to length \(N\): \[ \begin{aligned} Z^{\text{bosons}}_N & = \frac{1}{N!}\underbrace{\sum_P Z^P_N}_{\substack{\text{total weight of}\\ \text{all permutations}\\ \text{of }N \text{ elements}}}\\ & = \frac{1}{N!} \cdot \underbrace{\sum_{k = 1}^N}_{\substack{\text{loop over all}\\ \text{possible}\\ \text{last element}\\ \text{cycle lengths}}} \bigg( \underbrace{z_k}_{\substack{\text{weight of a last}\\ \text{element cycle of} \\ \text{length }k }} \cdot \underbrace{C^{N-1}_{k-1}}_{\substack{\text{ways to choose the}\\ \text{remaining } k-1\\ \text{elements in the}\\ \text{last element cycle}}} \cdot \underbrace{(k-1)!}_{\substack{\text{number of}\\ \text{unique cycles} \\ \text{of }k \text{ elements in}\\ \text{last element cycle}}} \cdot \underbrace{(\sum_{\substack{\text{permutation}\\Q}} Z^Q_{N-k})}_{\substack{\text{unconstrained}\\ \text{total weight of}\\ \text{the remaining}\\ N-k \text{ elements}}}\bigg)\\ & = \frac{1}{N!} \cdot \sum_{k = 1}^N \bigg( z_k \cdot \frac{(N-1)!}{(k-1)!(N-k)!} \cdot (k-1)! \cdot (N-k)!Z^{\text{bosons}}_{N-k}\bigg)\\ & = \frac{1}{N}\sum_{k = 1}^N z_k Z^{\text{bosons}}_{N-k} \end{aligned} \] \(Z^{\text{bosons}}_N\) can be calculated entirely from partition functions \(Z^{\text{bosons}}_M\) with \(M < N\) and single particle partition functions \(z(k\beta) = z_k(\beta)\) with \(k \leq N\), which we know how to compute from analytical solution. From this recursive relationship, we can find the probability of the last element cycle (the cycle that contains particle \(N\)) having length \(k\). \[ \underbrace{Z^{\text{bosons}}_N}_{\substack{\text{total statistical}\\ \text{weight of }N \text{ bosons}}} = \underbrace{ \frac{1}{N} z_1 Z^{\text{bosons}}_{N-1} }_{\substack{\text{weight of last}\\ \text{element cycle}\\ \text{having length }1}} + \underbrace{ \frac{1}{N} z_2 Z^{\text{bosons}}_{N-2} }_{\substack{\text{weight of last}\\ \text{element cycle}\\ \text{having length }2}} + \; ... \; + \underbrace{ \frac{1}{N} z_N Z^{\text{bosons}}_{0} }_{\substack{\text{weight of last}\\ \text{element cycle}\\ \text{having length }N}} \] \[ \pi_k = \frac{\frac{1}{N} z_k Z^{\text{bosons}}_{N-k}}{Z^{\text{bosons}}_N} = \frac{1}{N} \frac{z_k Z^{\text{bosons}}_{N-k}}{Z^{\text{bosons}}_N} \propto z_k Z^{\text{bosons}}_{N-k} \] where \(\pi_k\) is the probability of the last element cycle having length \(k\).

Algorithm (Main Loop)

The last equation allows us to sample all random permutations of the spatial coordinates of \(N\) ideal bosons following these steps:

1. Compute the values of \(z_k(\beta) = z(k\beta) \equiv \sum_{s}e^{-k\beta E_s}\) from single particle energy levels. Compute the values of \(Z_{N-k}\) for \(k = 1,..., N\) from the recursive relationship \(Z^{\text{bosons}}_N = \frac{1}{N}\sum_{k = 1}^N z_k Z^{\text{bosons}}_{N-k}\) and the trivial starting condition \(Z^{\text{bosons}}_0 = 1\).

2. Recursively sample from the probabilities \(z_1Z_{M-1},\,...\,,z_MZ_0\) to get the length \(k\) of the last element cycle, starting with \(M = N\), then \(M = N-k\), and so on. Save the total number of cycles and their lengths. For example, \(4\) cycles of length \(5\), \(3\) cycles of length \(4\), \(8\) cycles of length \(3\), etc.

3. For each cycle generated in step 2, because \(z_k(\beta) = z(k\beta)\), we can sample the \(k\) particle coordinates as if they were nodes on a path of a Wiener process, with time increment \(\beta\), over a finite horizon of \(k\) time units.

4. For particles in 3d, repeat step 3 to get the \(x\), \(y\), and \(z\) coordinates of each particle.

Single Free Particle in Periodic Box

There are two things we still need to implement the algorithm. First, we need the partition function of the single free particle in a periodic box, to compute \(z_k\) in Step 1. Second, we need to derive its density matrix, so we can use the probability distribution to sample the cycles (paths of the Wiener process) in Step 3.

To find the partition function, we start from the Schrödinger equation of a single free particle in a 1-dimensional box. The free particle wave function \(\psi(x)\) solves the time-independent Schrödinger equation \(\hat{H}\psi = E\psi\), where \(\hat{H} = -\frac{\hbar^2}{2m}\frac{d^2}{d x^2}\), with a periodic boundary condition. \(L\) is the length of the box. \[ -\frac{\hbar^2}{2m}\frac{d^2}{d x^2} \psi = E\psi \] \[ \text{(B.C.) }\;\; \psi(x+L) = \psi(x) \] The solutions (eigen functions and energy levels) are \[ \psi_n(x) = \sqrt{\frac{1}{L}}\exp( \frac{\mathrm{i}2n\pi x}{L} ) \] \[ E_n = \frac{2\pi^2 \hbar^2 n^2}{mL^2} \] \[\text{where }n = -\infty, ..., -2, -1, 0, 1, 2, ..., \infty\] The (1-dimensional) single particle partition function is: \[ z_k(\beta) = z(k\beta) = \sum_{n = -\infty}^{\infty} e^{-k \beta E_n} \] Since the energy level grows with \(n^2\), the exponential in \(z(k\beta)\) decays quickly. For the numerical solution, we can truncate \(n\) at \(n_{max} \approx 10\), or truncate when \(e^{-k \beta E_n}\) is near floating point error.

For a 3-dimensional box, the partition function is \[ z_k(\beta) = z(k\beta) = \bigg(\sum_{n = -\infty}^{\infty} e^{-k \beta E_n}\bigg)^3 \] The elements of the density matrix of the (1-dimensional) particle are \[ \begin{aligned} \rho^{\text{per, }L}(x,x',\beta) & = \sum_{n = -\infty}^{\infty}\psi_n(x)e^{-\beta E_n}\psi_n^*(x')\\ & = \frac{1}{L}\sum_{n = -\infty}^{\infty} \exp\bigg(\frac{\mathrm{i}2n\pi x}{L}\bigg)\exp\bigg(- \frac{2\pi^2 \hbar^2 n^2 \beta}{mL^2}\bigg)\exp\bigg(-\frac{\mathrm{i}2n\pi x'}{L}\bigg)\\ & = \frac{1}{L}\sum_{n = -\infty}^{\infty} \exp\bigg(\frac{\mathrm{i}2n\pi (x-x')}{L}\bigg)\exp\bigg(- \frac{2\pi^2 \hbar^2 n^2 \beta}{mL^2}\bigg) \end{aligned} \] Let \(f(n) \equiv \exp\big(\frac{\mathrm{i}2n\pi (x-x')}{L}\big)\exp\big(- \frac{2\pi^2 \hbar^2 n^2 \beta}{mL^2}\big)\). Then \(f(n)\in C^{\infty}(\mathbb{R})\), and \(n^{\alpha}\mathrm{d}^{(l)}f(n)\) is bounded for every pair of \(\alpha,l\in \mathbb{Z_{\geq 0}}\), that is, \(f(n)\) is a complex-valued smooth function whose derivatives are rapidly decreasing. Hence, \(f(n)\) is a Schwartz function, and we can apply the Poisson summation formula: \[ \sum_{n=-\infty}^{\infty} f(n) = \sum_{w=-\infty}^{\infty} \hat{f}(w) \] where \(\hat{f}(w)\) are the Fourier coefficients of \(f(n)\): \[ \hat{f}(w) = \int_{-\infty}^{\infty} f(n)e^{-2\pi \mathrm{i} n w} dn \] Substituting this back to \(\rho^{\text{per, }L}(x,x',\beta)\), we get: \[ \begin{aligned} \rho^{\text{per, }L}(x,x',\beta) & = \frac{1}{L}\sum_{w=-\infty}^{\infty} \hat{f}(w)\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\int_{-\infty}^{\infty} \exp\bigg(\frac{\mathrm{i}2n\pi (x-x')}{L}\bigg)\exp\bigg(- \frac{2\pi^2 \hbar^2 n^2 \beta}{mL^2}\bigg)\exp(-2\pi \mathrm{i} n w) dn\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\int_{-\infty}^{\infty} \exp\bigg(\frac{\mathrm{i}2n\pi (x-x' - wL)}{L}\bigg)\exp\bigg(-\frac{2\pi^2 \hbar^2 n^2 \beta}{mL^2}\bigg) dn \end{aligned} \] Let \(a = \frac{4\pi^2 \hbar^2\beta}{mL^2}\), \(b = \frac{2\pi (x-x' - wL)}{L}\). The integral becomes \[ \begin{aligned} \rho^{\text{per, }L}(x,x',\beta) & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\int_{-\infty}^{\infty} \exp\bigg(\mathrm{i}bn\bigg)\exp\bigg(-\frac{1}{2}an^2\bigg) dn\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\int_{-\infty}^{\infty} \exp\bigg(-\frac{1}{2}a(n^2 - \mathrm{i}\frac{2b}{a}n)\bigg) dn\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\int_{-\infty}^{\infty} \exp\bigg(-\frac{1}{2}a(n^2 - \mathrm{i}\frac{2b}{a}n - \frac{b^2}{a^2} + \frac{b^2}{a^2})\bigg) dn\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\exp\bigg(-\frac{b^2}{2a}\bigg)\int_{-\infty}^{\infty} \exp\bigg(-\frac{1}{2}a(n- \mathrm{i}\frac{b}{a})^2\bigg) dn\\ & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\exp\bigg(-\frac{b^2}{2a}\bigg)\sqrt{\frac{2\pi}{a}} \end{aligned} \] In the last line, because of the presence of the imaginary unit \(\mathrm{i}\), to evaluate the integral we must use Cauchy's Integral Theorem, which states that a holomorphic function \(f(z)\) satisfies \(\oint_C f(z) dz = 0\) for all closed loops \(C\). (Here \(\mathrm{Re}(a) = \frac{4\pi^2 \hbar^2\beta}{mL^2}\) clearly \(> 0\), and \(f(z) = \exp(-\frac{1}{2}az^2)\) for \(z\in \mathbb{C}\)). Substituting \(a\), \(b\) back, we get \[ \begin{aligned} \rho^{\text{per, }L}(x,x',\beta) & = \frac{1}{L}\sum_{w=-\infty}^{\infty}\exp\bigg(-\frac{(\frac{2\pi (x-x' - wL)}{L})^2}{\frac{8\pi^2 \hbar^2\beta}{mL^2}}\bigg)\sqrt{\frac{2\pi}{\frac{4\pi^2 \hbar^2\beta}{mL^2}}}\\ & = \sqrt{\frac{m}{2\pi \hbar^2\beta}}\sum_{w=-\infty}^{\infty}\exp\bigg(-\frac{m(x-(x' + wL))^2}{2\hbar^2\beta}\bigg) \end{aligned} \] Compare this to the density matrix without the periodic boundary condition: \[ \rho^{\text{free}}(x, x', \beta) = \sqrt{\frac{m}{2\pi\hbar^2 \beta}} \exp\bigg(-\frac{m(x-x')^2}{2\hbar^2\beta}\bigg) \] In the periodic boundary case, \(w\) is the winding number, which is the number of times the particle winds around the box of length \(L\). The density matrix in a periodic box is thus the sum of the free particle's density matrix over all winding numbers \(w\): \[ \rho^{\text{per, }L}(x,x',\beta) = \sum_{w=-\infty}^{\infty}\rho^{\text{free}}(x, x'+wL, \beta) \] where each \(w\) carries a statistical weight that is \(\rho^{\text{free}}(x, x'+wL, \beta)\). For the Monte Carlo simulation of a cycle of length \(k\) with coordinates \(x_{m}\), ..., \(x_{m+k-1}\), we can therefore sample \(w\) from the (unnormalized) probabilities \(\rho^{\text{free}}(x_m, x_m+wL, k\beta)\) and construct a Brownian path with time increment \(\Delta_{\tau} = \beta\). This is a Brownian bridge starting from \(x_m\) at time \(0\) and arrives at \(x_m + wL\) at time \(k\beta\).

In a 3-dimensional box, \(x = (\eta,\zeta,\xi)\), the density matrix is \[ \begin{aligned} \rho^{\text{per, }L}(x,x',\beta) & = \rho^{\text{per, }L}(\eta,\eta',\beta)\cdot \rho^{\text{per, }L}(\zeta,\zeta',\beta) \cdot \rho^{\text{per, }L}(\xi,\xi',\beta) \end{aligned} \] and each spatial component has its own winding number that is independent from the others.

Now we have everything we need to build the simulation. You can find the pseudocode at the bottom of this page.

Simulation

This applet simulates ideal Bose gas in a 3-dimensional periodic box of length \(L\). The simulation shows a 2d projection of the box. At low temperature, you can see the Bose-Einstein Condenstate forming.

///////////// GLOBAL VARIABLES /////////////
double beta // inverse temperature (time horizon)
double L // length of box
int N // number of bosons
double bosonsX[N] // array of size N that stores the x coordinates of bosons
double bosonsY[N] // array of size N that stores the y coordinates of bosons
double bosonsZ[N] // not needed for xy-plane projection

// cycle weight of length k (from 1 to N) / single particle partition function
// array of size N all initialized to zero
double zk[N] = 0

// Bosons partition function (from 0 bosons to N bosons)
// array of size N+1
double Z_bosons[N+1] = 0
Z_bosons[0] = 1 // initialize Z_0 = 1

// stores the number of permutatine cycles of length from 1 to N
// array of size N, all initialized to zero
int cycle_count[N] = 0

// for simplicity, set hbar = m = 1
double hbar = 1
double m = 1

// for visualization with heatmap
int grid_size = 50;
double cellSizeX = L / grid_size;
double cellSizeY = L / grid_size;
double heatmap[grid_size][grid_size]

max_iter = 100000

///////////// HELPER FUNCTIONS /////////////
// May use built in functions from libraries

// sample from a list where the items occur with probabilities p1, p2, ...
// array of (unnormalized) probabilities as input
// returns index of the sampled item
function sample(prob){
  // normalize probabilities
  double sum = 0;
  for i from 0 to prob.length - 1 {
    sum += prob[i];
  }

  double normalized_prob[prob.length] = all zeros;
  for i from 0 to prob.length - 1 {
    normalized_prob[i] = prob[i]/sum;
  }

  // build tower of cumulative probabilities
  double tower_prob[prob.length] = all zeros;
  tower_prob[0] = normalized_prob[0];
  for i from 1 to prob.length - 2 {
    tower_prob[i] += normalized_prob[i-1];
  }
  tower_prob[prob.length - 1] = 1;

  // generate random number from 0 to 1
  r = rand(0,1);

  // find out which bracket r belongs in
  int prob_index = 0;
  int min_index = 0;
  int max_index = prob.length;
  while(true) {
    // bisection for efficiency
    prob_index = round((min_index + max_index)/2);

    if (tower_prob[prob_index] < r) {
      min_index = prob_index;
    } else if (tower_prob[prob_index] > r) {
      max_index = prob_index;
    } else {
      break;
    }
  }

return prob_index;

}

// sample from normal distribution
// Box Muller transform
function norm_rand(mu, sigmasq) {
  u1 = rand(0,1);
  u2 = rand(0,1);
  z0 = sqrt(-2*log(u1))*cos(2*pi*u2);
  return z0*sqrt(sigmasq) + mu
}

// sample a random number (double) between min and max
function rand(min, max){
  double r = rand(0,1);

  return r*(max-min) + min;
}


///////////// COMPUTATIONS /////////////
function main(){

  // compute single particle partition function
  compute_zk();
  // compute partition function for N particles
  compute_Z(zk);

  // Monte Carlo loop
  // Sample N particle positions, repeat max_iter times
  for iter from 0 to max_iter, iter++ {

    // reset cycle counts
    cycle_count = all zeros;

    // sample permutation cycles
    sample_cycles();

    // particle index count
    int index = 0;

    // compute coordinates of particles in each cycle, length from 1 to N
    for i from 0 to N-1 {
      // skip if the number of cycles of length i+1 is zero
      if (cycle_count[i] == 0){
        continue;
      } else {
        // sample coordinates of each cycle of length i+1
        // cycle_count[0] is the number of cycles of length 1, and so on
        for j from 1 to cycle_count[i] {

          // x direction
          // random starting coordinate of first particle
          double x_start = rand(0, L);
          // sample a winding number
          int wx = sample_w(x_start, x_start, (i+1)*beta);
          // sample a path of length i+1
          // "1" - x direction
          brownian_bridge(x_start, x_start + wx*L, (i+1)*beta, beta, 1, index);

          // y direction
          // random starting coordinate of first particle
          double y_start = rand(0, L);
          // sample a winding number
          int wy = sample_w(y_start, y_start, (i+1)*beta);
          // sample a path of length i+1
          // "2" - y direction
          brownian_bridge(y_start, y_start + wy*L, (i+1)*beta, beta, 2, index);

          // z direction, not needed for bird view projection

          // increment index
          index += i+1
        }
      }
    }

    // register x and y coordinates of N particles to heatmap
    for idx from 0 to N-1 {
      // go throught the coordinates of particles and add to heatmap cell
      int cellIndex_x = floor(bosonsX[idx]/cellSizeX);
      int cellIndex_y = floor(bosonsY[idx]/cellSizeY);
      if (cellIndex_x == grid_size){
        cellIndex_x--;
      }
      if (cellIndex_y == grid_size){
        cellIndex_y--;
      }
      heatmap[cellIndex_x][cellIndex_y] += 1;
    }

    // clear current particle coordinates for next iteration
    bosonsX = all zeros
    bosonsY = all zeros
  }

  // normalize heatmap
  double heatmap_sum = 0;
  for i from 0 to grid_size - 1 {
    for j from 0 to grid_size - 1 {
      heatmap_sum += heatmap[i][j];
    }
  }
  for i from 0 to grid_size - 1 {
    for j from 0 to grid_size - 1 {
      heatmap[i][j] = heatmap[i][j]/heatmap_sum;
    }
  }

}

function compute_zk() {
  // for cycle length from 1 to N
  for k from 1 to N {
    double sum = 0;

    // e^(k beta E_s) is an even function
    // only calculate for positive s
    int s = 0;
    while (true) {
      // energy level
      E_s = 2*pi^2*hbar^2*s^2/(m*L^2);
      // compute e^(k beta E_s)
      z = exp(-k*beta*E_s);

      // stop loop if z is very small
      if (z < 0.0000000000000002){
        break;
      }

      // times 2 for the negative side (even function)
      if (s > 0){
        z *= 2;
      }
      // add to sum and increment s
      sum += z;
      s++;
    }
    // cube sum for 3-dimensional box
    sum = sum^3;
    // store value of zk
    zk[k-1] = sum;
  }
}

function compute_Z(zk) {
  // Recursively calculate Z_N
  // Z_0 = 1
  for m from 1 to N {
    // Use recursive formula to compute Z
    for k from 1 to m {
      Z_bosons[m] += zk[k-1]*Z_bosons[m-k];
    }
    Z_bosons[m] *= 1/m;
  }
}

function sample_cycles(){

  // declare a variable to keep track of the number of particles left
  int M = N

  // Recursively sample cycle lengths using these probabilities
  while (M > 0) {
    // declare a variable to store probabilities of cycle length
    double current_prob[M]
    // compute the probabilities
    for k from 1 to M {
      current_prob[k-1] = zk[k-1]*Z_bosons[M-k];
    }

    // sample length of last element cycle
    int l = sample(current_prob) + 1;
    // number of remaining particles
    M = M-l;
    // increment count for cycles of length l
    cycle_count[l-1] += 1;
  }
}

function brownian_bridge(x_start, x_end, T, dt, dir, index) {
  // number of nodes in the path
  int length = floor(T/dt);

  // coordinates of first node
  // "1" - x direction
  // "2" - y direction
  // "3" - z direction (not needed for xy-plane projection)
  if (dir == 1){
    // make the result stay in the visualization window,
    // add L to prevent negative value
    bosonsX[index] = x_start;
  } else if (dir == 2){
    bosonsY[index] = x_start;
  } else {
    bosonsZ[index] = x_start;
  }

  // generate new nodes between (not inclusive) start and end
  for i from 1 to length-1 {
    // compute mean and variance of the inbetween nodes of the brownian bridge
    // one step at a time
    mean = x_start + (1/(length-i+1))*(x_end - x_start);
    variance = (hbar^2/m)*(length-i)*dt/(length-i+1);

    // take a sample from normal distribution
    new_x = norm_rand(mean, variance);

    // update x_start
    x_start = new_x

    // modify value of bosonsX, bosonsY, bosonsZ
    if (dir == 1){
      // make the result stay in the visualization window,
      // add L to prevent negative value
      bosonsX[index+i] = new_x - L*floor(new_x/L);
    } else if (dir == 2){
      bosonsY[index+i] = new_x - L*floor(new_x/L);
    } else {
      bosonsZ[index+i] = new_x - L*floor(new_x/L);
    }
  }
}

sample_w(x_start, x_end, inv_T){
  int result

  // compute constant factors
  // probability proportional to exp(-b*(x_start-(x_end+w*L))^2)
  double b = m/(2*hbar^2*inv_T);

  // find the max winding number until floating point error
  // generic x_start and x_end
  int w_0 = round((x_start - x_end)/L);
  int offset = 0;
  while (true) {
    double p_plus = exp(-b*(x_start-(x_end+(w_0 + offset)*L))^2);
    double p_minus = exp(-b*(x_start-(x_end+(w_0 - offset)*L))^2);

    // stop loop when both are small
    if (p_plus < 0.0000000000000002 && p_minus < 0.0000000000000002){
      break;
    }
    //increment offset
    offset++;
  }

  // w range: [w_0 - offset, w_0 + offset]
  // declare a variable to store these probabilities
  // array size 2*offset + 1
  double pr[2*offset + 1];

  // compute probabilities
  for i from 0 to 2*offset {
    int w = w_0 - offset + i;
    pr[i] = exp(-b*(x_start-(x_end+w*L))^2);
  }

  // sample from probabilities
  result = sample(pr);

  // convert result to actual winding number
  result += w_0 - offset;

  return result;
}
