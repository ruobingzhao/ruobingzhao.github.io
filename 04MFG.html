4. Mean Field Games Demo

Back to Contents
This is a simulation of crowd behavior in an evacuation (Click here to jump to simulation). Each agent tries to get to the exit as fast as possible, but if every agent rushes to the exit via the shortest path, the path becomes congested. In the Mean Field Games system, (infinitely many) interacting agents choose their paths based on not just the distance to the exit, but also on the population density nearby, until an equilibrium is reached. The trajectory of an agent, \(X_t\), evolves in time: \[ dX_t = b(X_t, u_t,\rho_t)dt + \sigma dW_t\] where \(u_t\) is the control (action) the agent adopts at time \(t\), \(\rho_t = \rho_t(x)\) is the population density at time \(t\) and location \(x\), and \(W_t\) is a Brownian motion that accounts for random noises. The initial population density distribution at time \(t=0\) is given by \(\rho_0(x)\) for all \(x\). An agent at location \(x\), time \(t\), seeks to minimize the cost-to-go function: \[J(t,x,u) = \mathbb{E}^{X_t=x}\bigg[\int_t^T L(X_s, u_s, \rho_s)ds + G(X_T, \rho_T)\bigg]\] The value function is defined as: \[V(t,x) = \inf_u J(t,x,u)\] with terminal conditon \(V(T,x) = G(x,\rho_T)\). This value function solves the Hamilton-Jacobi-Bellman (HJB) equation: \[-\frac{\partial V}{\partial t} - \frac{\sigma^2}{2}\nabla^2 V = \inf_u \bigg\{b(x,t,\rho)\cdot \nabla V + L(x,u,\rho)\bigg\} \] and the optimal control is \[u^* = \text{argmin}_u \bigg\{b(x,t,\rho)\cdot \nabla V + L(x,u,\rho)\bigg\}\] At the same time, the density function \(\rho_t(x)\) also evolves with time and satisfies the Fokker-Planck equation: \[\frac{\partial \rho}{\partial t} - \frac{\sigma^2}{2}\nabla^2 \rho = -\nabla \cdot (\rho b(x,u^*,\rho))\] An equilibrium pair \((V,\rho)\) satisfies both equations. The solution (existence and uniqueness given by Fixed-Point Theorems) can be found following an iterative algorithm: At iteration \(k\), given \(\rho^k\), solve the HJB equation ( propagates backward) to get \(V^k\) and extract \(u^*\), then use \(u^*\) to solve the Fokker-Planck equation (propagates forward), with initial condition \(\rho_0(x)\), to get \(\rho^{k+1}\). Repeat until a convergence criterion is satisfied.
This demo however, uses a discretized formulation of the MFG system. The agents dynamics follows: \[X_{t+1} = f(X_t, u_t, \rho_t) + \sigma W_t\] Agents at time \(t\), state \(x\), seek to minimize \[J(t,x,u) = \mathbb{E}^{X_t = x}\bigg[\sum_{s=t}^{T-1}L(X_s,u_s, \rho_s) + G(X_T, \rho_T)\bigg]\] The value function is \[V(t,x) = \inf_u J(t,x,u)\] which satisfies the (backward) Bellman equation: \[V(t,x) = \inf_u\bigg\{ L(x,u,\rho_t) + \mathbb{E}\big[V(t+1,x_{t+1})\big]\bigg\}\] \[V(t,x) = G(x, \rho_T)\] \[u^* = \text{argmin}_u \bigg\{ L(x,u,\rho_t) + \mathbb{E}\big[V(t+1,x_{t+1})\big]\bigg\}\] The density satisfies the initial condition \(\rho_0(x)\) and evolves forward in time following: \[\rho_{t+1}(x) = \sum_{x'}\rho_t(x')P(x|x', u^*(t,x'))\] where \(P(x|x', u^*(t,x'))\) is the transition probability from \(x'\) to \(x\) following control \(u^*\). An equilibrium pair \((V,\rho)\) satisfies both the Bellman equation and the density evolution equation.
This applet simulates such equilibrium. The exit is located on one side of the room (highlighted in green). Click the button to start simulation.
