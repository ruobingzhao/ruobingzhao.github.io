8. Zermelo's Navigation Problem (A Continuous-Time Stochastic Control Problem)

Back to Contents
In this demo we solve the Zermelo's Navigation Problem numerically as a continuous-time stochastic control problem using Markov Chain Approximation. Click here to play with the simulation.
The original (deterministic) Zermelo's Navigation Problem was formulated by Ernst Zermelo in his 1931 paper. A boat in a body of water (or, a zeppelin surrounded by air) is moving at its maximum motor speed \(k\) towards a destination against a variable water current (or wind) given by the vector field \(\vec{v} = (v_x, v_y)\). The boat seeks to minimize the time it takes to arrive at the destination. The boat position \((x,y)\) evolves according to the differential equations: \[ \dot{x} = v_x(x,y) + k\cos\theta_t \] \[ \dot{y} = v_y(x,y) + k\sin\theta_t \] where \(\theta_t\) is the angle between the boat's moving direction and the \(x\)-axis at time \(t\), which is the control variable. In this demo, we consider the stochastic case, where there is Brownian noise in the state evolution: \[ dX_t = \bigg(v_x(X_t,Y_t) + k\cos\theta_t\bigg)dt + \sigma dW^{1}_t \] \[ dY_t = \bigg(v_y(X_t,Y_t) + k\sin\theta_t\bigg)dt + \sigma dW^{2}_t \] Again \(\theta\) is the control variable, and \(W^{1}_t\), \(W^2_t\) are independent 1-dimensional Brownian motions, and \(\sigma >0\). The goal is to find the minimum mean exit time (and the optimal control policy) from an open set \(\mathcal{O}\in \mathbb{R}^2\), which represents the body of water, and its boundary \(\partial \mathcal{O}\) represents the destination (for example, an island, or the riverbanks). The objective function to be minimized is \[ J(x,y,\theta) = \mathbb{E}^{x,y} [\int_0^{\tau} 1\; dt] = \mathbb{E}^{x,y} [\tau], \;\; (x,y)\in \mathcal{O} \] \[ \tau = \inf\{s>0:\; (x_s,y_s) \notin \mathcal{O}\} \] \[ J(x,y) = 0, \;\; (x,y)\in \partial\mathcal{O} \] The value function is defined as the infimum of the objective function over all admissible controls, with the boundary condition \[ V(x,y) = \inf_{\theta}\, J(x,y,\theta) \] \[ V(x,y) = 0, \;\; \;(x,y)\in \partial \mathcal{O} \] The value function satisfies the Hamilton-Jacobi-Bellman (HJB) equation, along with the boundary condition: \[ \inf_{\theta}\bigg\{ \frac{\partial V}{\partial x} \cdot (v_x + k\cos\theta) + \frac{\partial V}{\partial y} \cdot (v_y + k\sin\theta) + \frac{1}{2}\sigma^2\bigg(\frac{\partial^2 V}{\partial x^2} + \frac{\partial^2 V}{\partial y^2}\bigg)+ 1\bigg\} = 0,\;\; (x,y)\in \mathcal{O} \] \[ V(x,y) = 0, \;\; \;(x,y)\in \partial \mathcal{O} \] For a numerical solution, we use finite difference with step size \(h>0\) to approximate the derivatives. For the first derivatives, we choose the left/right side difference depending on whether \(v_x + k\cos\theta\) and \(v_y + k\sin\theta\) are positive or negative. (This comes from the requirement of local consistency for Markov Chain Approximation, which will be explained later.) \[ \frac{\partial V}{\partial x} \approx \frac{V(x+h,y) - V(x,y)}{h} \;\;\text{ if }\;v_x + k\cos\theta \geq 0 \] \[ \frac{\partial V}{\partial x} \approx \frac{V(x,y) - V(x-h,y)}{h} \;\;\text{ if }\;v_x + k\cos\theta < 0 \] \[ \frac{\partial V}{\partial y} \approx \frac{V(x,y+h) - V(x,y)}{h} \;\;\text{ if }\;v_y + k\sin\theta \geq 0 \] \[ \frac{\partial V}{\partial y} \approx \frac{V(x,y) - V(x,y-h)}{h} \;\;\text{ if }\;v_y + k\sin\theta < 0 \] \[ \frac{\partial^2 V}{\partial x^2} \approx \frac{V(x+h,y)-2V(x,y)+ V(x-h,y)}{h^2} \] \[ \frac{\partial^2 V}{\partial y^2} \approx \frac{V(x,y+h)-2V(x,y)+ V(x,y-h)}{h^2} \] For any real number \(a\), let \(a^+ = \max[0,a]\), \(a^- = \max[0,-a]\), i.e. \(a^+\) and \(a^-\) denote the positive and negative parts of \(a\), so that \(a = a^+-a^-\) and \(|a| = a^++a^-\). Adopting the notation \(b_1 = v_x + k\cos\theta\), \(b_2 = v_y + k\sin\theta\), we can rewrite the HJB equation: \[ \begin{aligned} \inf_{\theta}\bigg\{ & 1 + \frac{V(x+h,y) - V(x,y)}{h} \cdot b_1^+ - \frac{V(x,y) - V(x-h,y)}{h} \cdot b_1^-\\ & + \frac{V(x,y+h) - V(x,y)}{h} \cdot b_2^+ - \frac{V(x,y) - V(x,y-h)}{h} \cdot b_2^-\\ & + \frac{1}{2}\sigma^2\bigg(\frac{V(x+h,y)-2V(x,y)+ V(x-h,y)}{h^2} + \frac{V(x,y+h)-2V(x,y)+ V(x,y-h)}{h^2}\bigg)\bigg\} = 0,\\ (x,y) \in & \;\mathcal{O} \end{aligned} \] Collecting terms, we get \[ \begin{aligned} \inf_{\theta}\bigg\{ & 1 + \bigg( \frac{b_1^+}{h} + \frac{\sigma^2}{2h^2} \bigg)V(x+h,y) \\ & + \bigg( \frac{b_1^-}{h} + \frac{\sigma^2}{2h^2} \bigg)V(x-h,y)\\ & + \bigg( \frac{b_2^+}{h} + \frac{\sigma^2}{2h^2} \bigg)V(x,y+h) \\ & + \bigg( \frac{b_2^-}{h} + \frac{\sigma^2}{2h^2} \bigg)V(x,y-h)\\ & - \bigg( \frac{b_1^+}{h} + \frac{b_1^-}{h} + \frac{b_2^+}{h} + \frac{b_2^-}{h} +\frac{2\sigma^2}{h^2} \bigg)V(x,y) \bigg\} = 0 \end{aligned} \] Note that \(b_1^+\), \(b_1^-\), \(b_2^+\), \(b_2^-\) are all non-negative numbers. We can define a Markov chain \(\,\xi_n^h = (\eta_n^h, \zeta_n^h)\,\) on the discrete state space \(S^h = \{(ih,jh): i,j\in \mathbb{Z}\}\), with transition probabilities \[ p^{h,\theta}(x+h,y|x,y) = \frac{b_1^+/h + \sigma^2/2h^2}{Q^{h,\theta}} \] \[ p^{h,\theta}(x-h,y|x,y) = \frac{b_1^-/h + \sigma^2/2h^2}{Q^{h,\theta}} \] \[ p^{h,\theta}(x,y+h|x,y) = \frac{b_2^+/h + \sigma^2/2h^2}{Q^{h,\theta}} \] \[ p^{h,\theta}(x,y-h|x,y) = \frac{b_2^-/h + \sigma^2/2h^2}{Q^{h,\theta}} \] \[ \text{where }\; Q^{h,\theta} = \frac{b_1^+}{h} + \frac{b_1^-}{h} + \frac{b_2^+}{h} + \frac{b_2^-}{h} +\frac{2\sigma^2}{h^2} \] \[ \text{Note that }\; \sum p^{h,\theta} = 1 \] Then this Markov chain is locally consistent with the continuous time state process, meaning that the mean, variance, and covariance of incremental changes in the Markov chain states are consistent with those of the continuous time stochastic process: \[ \mathbb{E}[\Delta \eta_n^h] = \big(v_x + k\cos\theta\big)\cdot \Delta_t^{h,\theta} \] \[ \mathbb{E}[\Delta \zeta_n^h] = \big(v_y + k\sin\theta\big)\cdot \Delta_t^{h,\theta} \] \[ \mathbb{E}\big[ \big(\Delta \eta_n^h - \mathbb{E}[\Delta \eta_n^h] \big)^2 \big] = \sigma^2 \Delta_t^{h,\theta} + o(\Delta_t^{h,\theta}) \] \[ \mathbb{E}\big[ \big(\Delta \zeta_n^h - \mathbb{E}[\Delta \zeta_n^h] \big)^2 \big] = \sigma^2 \Delta_t^{h,\theta} + o(\Delta_t^{h,\theta}) \] \[ \mathbb{E}\big[ \big(\Delta \eta_n^h - \mathbb{E}[\Delta \eta_n^h] \big)\big(\Delta \zeta_n^h - \mathbb{E}[\Delta \zeta_n^h] \big) \big] = 0 + o(\Delta_t^{h,\theta}) \] \[ \text{where }\; \Delta_t^{h,\theta} = \frac{1}{Q^{h,\theta}} \] Let us consider the discrete-time control problem with this Markov chain \(\xi_n^h\). Suppose we are minimizing the mean exit time of \(\xi_n^h\) from a set \(\mathcal{O}^h = \mathcal{O}\cap S^h\) in the discrete state space, defined as \[ \tau^{h,\theta} = \sum_{s = 0}^{N-1} \Delta_t^{h,\theta_n} \;\;\text{ where }N = \min \{ n>0: \xi_n^h \notin \mathcal{O}^h \} \] Then the value function is \[ V^h(x,y) = \min_{\theta} \mathbb{E}^{x,y}[\tau^{h,\theta}] \] which satisfies the Bellman equation \[ V^h(x,y) = \min_{\theta}\mathbb{E}\big[ \Delta_t^{h,\theta} + V^h(\xi_{n+1}^h)\;|\;\xi_n^h = (x,y)\big] \] or, written with transition probabilities (compare this to the HJB equation earlier) \[ \begin{aligned} V^h(x,y) = \min_{\theta}\bigg\{ & \Delta_t^{h,\theta} + p^{h,\theta}(x+h,y|x,y)\cdot V^h(x+h,y) + p^{h,\theta}(x-h,y|x,y)\cdot V^h(x-h,y)\\ & + p^{h,\theta}(x,y+h|x,y)\cdot V^h(x,y+h) + p^{h,\theta}(x,y-h|x,y)\cdot V^h(x,y-h) \bigg\} \end{aligned} \] The value function satisfies the boundary condition \[ V^h(x,y) = 0,\; \; (x,y) \in \partial \mathcal{O}^h \] The discrete time control problem can be solved using standard methods such as value iteration. As \(h\to 0\), the Markov chain \(\xi_n^h\) converges weakly to the continuous-time stochastic process, and the value function \(V^h(x,y)\) converges to the value function of the continuous-time control problem, \(V(x,y)\). Detailed discussion on convergence can be found in Chapter 10 and Chapter 16 of [2].




Reference

[2] H.J. Kushner, P. Dupuis (2001), Numerical Methods for Stochastic Control Problems in Continuous Time, Springer.

Simulation

This applet simulates the Zermelo's Navigation Problem. The boat is dropped at a random location in the map (length of map: \(5\), width: \(4\)). The boat location evoles with time and follows the stochastic differential equations: \[ dX_t = \bigg(v_x(X_t,Y_t) + k\cos\theta_t\bigg)dt + \sigma dW^{1}_t \] \[ dY_t = \bigg(v_y(X_t,Y_t) + k\sin\theta_t\bigg)dt + \sigma dW^{2}_t \] where \(k = 0.5\) is the motor speed of the boat, and \(\sigma = 0.1\) is the diffusion coefficient that controls the random choppiness of the water due to a storm. The maximum calm water speed is approximately \(0.4\) for the one directional and sinusoidal vector field, and approximately \(0.48\) for the whirlpool. The target island is indicated by the yellow circle.

Calm water current vector field \(\vec{v} = (v_x,v_y)\):

Sinusoidal Sinusoidal (other direction)
