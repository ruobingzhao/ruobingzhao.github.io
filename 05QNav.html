5. Navigating Unknown Terrain via Q-Learning

Back to Contents
This is a simulation of an agent exploring an unfamiliar environment. The agent starts out with zero knowledge about the map, the different terrains, and the difficulty (cost) to cross each type of terrain. The agent learns from experience and finds an optimal path, which minimizes the total cost to reach the goal (lower right corner). The arrows indicate learned optimal control in each cell. The agent can follow the arrows to reach the goal.
gray = road, green = grass, brown = mud, blue = pond, black = wall/pit, white = goal
cost-to-enter: road 0.5, grass 1, mud 3, pond 5, wall/pit = Infinity, goal 0
