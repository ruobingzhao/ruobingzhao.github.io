5. Navigating Unknown Terrain via Q-Learning

Back to Contents
This is a simulation of an agent (located in the upper left corner, highlighted in red) exploring an unfamiliar environment. The agent starts out with zero knowledge about the map, the different terrains, and the difficulty (cost) to traverse each type of terrain. The agent learns from experience and finds an optimal path, which minimizes the total cost to reach the goal (lower right corner, highlighted in green), while balancing the risk of hitting obstacles. The arrows indicate learned optimal control in each cell. The agent can follow the arrows to reach the goal. The learning curve helps visualize the agent's learning process. It records the total cost of each learning episode. The total cost per episode decreases with more episodes until it stabilizes near the minimum value, when the agent has found the optimal path (highlighted in orange).
In classical discrete-time optimal control, the agent solves for the value function (minimum cost-to-go from state \(x\) over control \(u\)) using backward dynamic programming \[V(x) = \min_u \{L(x,u) +\gamma V(x')\}\] where \(L(x,u)\) is the one-step cost of taking action \(u\) from state \(x\), \(\gamma\) is the discount factor (set to \(1\) for finite grid), and \(x'\) is the next state after taking action \(u\). In the Q-Learning approach, the agent evaluates the quality of each state-action pair \((x,u)\), which is defined as \[Q(x,u) = L(x,u) + \gamma\min_{u'}Q(x',u').\] The agent does not need to know anything about the environment, but only interacts and observes. Under an \(\epsilon\)-greedy exploration policy, it updates the \(Q\)-table using temporal difference between visits to the state-action pair: \[Q(x,u)\leftarrow Q(x,u) + \alpha[L(x,u)+ \gamma\min_{u'}Q(x',u') - Q(x,u)]\] with learning rate \(\alpha\), until the optimal path is found.
